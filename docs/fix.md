# 修正して欲しい点

## 全般

- 英語のサイトを模倣してる感じがある。いわゆるタイトルのフォントでかすぎる等
- fqdn/'locale'/ のlocaleが忘れている。正しくページ遷移できないときがある。そもそもlocaleを必須にする。localeが無い時はjaのフォールバック
- fontは一旦robotoで統一
- 全てのコンポーネントがカードのようになっている。カードいらない。
- 角丸すぎるデザインを避ける
- footer作る
- mobileでheaderがでかすぎる. 小さくするかハンバーガーメニューなど検討
- ページの横がはみ出している
- ja/enで言語が切り替わってない。.jsonとかにenあるので適切に処理
- 設定をrxjsで保持検討
- 黄色が買ってるのをやめる。ライトモードは白, ダークモードは灰色(#000は避ける)

## ページ単位

### home

- 検索への導線が弱い
- 代表タグ/データセットは削除
- buildIdのみ下部に小さく表示。

### search

- tagはselectorなので初めから全件表示はやめる
  - タップで展開して複数選択可能なやつ
- channelもartist同様に検索できるようにする
  - artistの検索インデックス使ってliver_idからchannel_idを引く
- 日付検索は月単位での検索がデフォルト。
  - カレンダーを開いたとき、月が開くように
- 検索は検索結果の件数は常に表示して、確定するまで具体的なクリップは表示しない
  - mobile: 具体的なクリップを表示するときも、ページを一番上までスクロールしなくても条件を見れるように固定か少しでも下にスクロールしたら出てくるやつ
- playable, blockedの表示はいらない。そもそもblockedは検索結果に出さない。

### play

- queueの保存がきもい。
  - ユーザが保存/共有しにくい
- angularのyoutube api使う
  - auto playいる
- クリップの再生時間を表示するバーいる
- 一時停止/再生ボタンいる
- 元動画へのリンクいる
- 動画の公開時間の表示は必要だがh:mはいらない。Dateまで
- youtubeのデザインのようにする。
  - ページ自体はスクロール無効化
  - queueは仮想DOMでもいい
  - queueだけ応じてスクロールできるように

### settings

- このページは必要
- 言語の切り替えなどをする
- site_design.mdみて設定が必要な記述があるやつはここで変更
- 前回居たurlに戻るボタンいる
  - ただむやみに履歴の一番目を採用するのではなく、前が自分のドメインか確かめる
  - 前が自分のドメインで無ければhomeに飛ばす
